登入

用你的 GitHub 帳號建立的「存取權杖（token）」登入。只有被加入 repo、且有寫入權限的人能修改內容。

  1. 到 GitHub 建立 fine-grained token ↗
  2. Resource owner 選 repo 的擁有者；Repository access 選 Only select repositories → 只勾選 本網站的 repo
  3. Permissions → Repository permissions → Contents 選 Read and write（其他都不用開）
  4. 建立後複製 token（github_pat_ 開頭），貼到下方

按下儲存後會立即修改公開網站（約 1～2 分鐘後生效），並在 GitHub 留下修改紀錄。

網站與 repo 皆為公開：不要放任何個人資料（電話、身分證字號、住址等）。
